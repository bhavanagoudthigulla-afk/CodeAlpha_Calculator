
# 🧮 Smart Calculator

## 📌 Project Overview

Smart Calculator is a modern, responsive calculator developed using HTML, CSS, and JavaScript. It provides a simple and attractive user interface for performing basic arithmetic calculations efficiently.

This project was developed as part of the **CodeAlpha Frontend Development Internship — Task 2: Build a Calculator**.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 💯 Percentage calculations
- 🔢 Decimal number support
- 🧹 Clear all (AC) functionality
- ⌫ Delete last character (DEL)
- ➕➖ Positive and negative number toggle
- ⌨️ Keyboard support
- ⚡ Real-time display updates
- ⚠️ Error handling for invalid calculations
- 📱 Responsive design for different screen sizes
- 🎨 Modern dark theme with gradient styling and hover effects

## 🛠️ Technologies Used

- **HTML5** — Structures the calculator interface.
- **CSS3** — Provides styling, layout, animations, and responsiveness.
- **JavaScript** — Implements calculator operations and event handling.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in VS Code.

**Note:** No additional packages or installations are required.

## 🎮 How to Use

1. Click the number buttons to enter values.
2. Select an arithmetic operator.
3. Enter the next number.
4. Press `=` to display the result.
5. Use `AC` to clear the calculation.
6. Use `DEL` to delete the last character.
7. Use `%` for percentage calculations.
8. Use `+/−` to toggle the sign of a number.

### Keyboard Shortcuts

| Key | Function |
|---|---|
| 0–9 | Enter numbers |
| +, -, *, / | Arithmetic operations |
| Enter or = | Calculate result |
| Backspace | Delete last character |
| Escape | Clear calculator |
| % | Percentage |
